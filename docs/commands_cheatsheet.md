# FRIDAY Voice Commands Cheat Sheet

## Window Management
- `Tile Left`: Dock active window to the left half.
- `Tile Right`: Dock active window to the right half.
- `Maximize`: Maximize current window.

## Voice Commands in Hindi
- `क्रिएट फोल्डर [Name]`: Desktop folder creation.
- `क्रिएट फाइल [Name]`: Desktop file creation.
- `स्पॉटिफाई चलाओ`: Instant media playback.
