## 🎙️ Voice Microphone Mode Kaise Use Karein?

1. Desktop App me Glowing **Voice Orb** (circle button) par click karein.
2. Orb glowing status change karega (*"Recording mic... Speak now"*).
3. **4 Seconds ke andar** upar di gayi koi bhi command bolein (e.g. *"Open Spotify"*, *"Mute sound"*, *"Start coding mode"*).
4. FRIDAY aapki voice command transcribe karke automation run karega aur **Voice AI Reply** dega.
