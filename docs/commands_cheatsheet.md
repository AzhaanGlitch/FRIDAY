# FRIDAY AI Assistant - Voice & Text Command Cheat Sheet

Complete reference guide for all **FRIDAY Voice & Text Commands** across macOS & Windows.

---

## 📱 1. Applications & Window Tiling
| Task | Voice / Text Command | Action Executed |
| :--- | :--- | :--- |
| **App Open** | `"Open Spotify"`, `"Open Calculator"`, `"Launch VSCode"` | Launches application |
| **App Close** | `"Close Spotify"`, `"Quit Chrome"`, `"Band kardo Calculator"` | Closes application |
| **4-Corner Tiling** | `"Chrome top-left me, VS Code right me, Terminal bottom-left me"` | Tiles windows precisely in corners |
| **Multi-App Tiling** | `"Tile Chrome and VS Code"`, `"Split screen Spotify and Terminal"` | 2, 3, or 4 app auto-grid tiling |
